# 🔥 WEB VISUALISASI TITIK KEBAKARAN HUTAN DI RIAU

## 📌 Deskripsi
Proyek ini adalah sebuah website berbasis **OpenLayers** Sederhana yang digunakan untuk **menampilkan titik lokasi kebakaran hutan di Riau** secara interaktif. Dengan menggunakan peta dinamis, pengguna dapat melihat lokasi kebakaran berdasarkan data yang tersedia.

## 🚀 Fitur Utama
- 🗺️ **Visualisasi titik kebakaran hutan** di wilayah Riau menggunakan **OpenLayers**.
- 📍 **Pemetaan interaktif** dengan tampilan yang mudah dipahami.
- 📄 **Data kebakaran berasal dari file JSON** yang telah disediakan.
- 🌍 **API hanya digunakan untuk menampilkan peta**, bukan untuk pembaruan data kebakaran.
- 📊 **Filter dan pencarian data lokasi** (fitur yang bisa dikembangkan lebih lanjut).

## 🛠️ Instalasi
1. **Clone repository ini:**
    ```sh
    git clone https://github.com/Hann000/Simple-SIG-KebakaranHutan.git
    ```
2. **Masuk ke direktori proyek:**
    ```sh
    cd Simple-SIG-KebakaranHutan
    ```
3. **Install dependensi (jika menggunakan npm/yarn):**
    ```sh
    npm install
    ```
4. **Jalankan proyek (jika ada server development):**
    ```sh
    npm start
    ```
5. **Atau cukup buka file `index.html` di browser untuk melihat tampilan.**

## 📖 Cara Penggunaan
1. **Buka Website** melalui browser.
2. **Navigasi Peta** untuk melihat lokasi kebakaran hutan.
3. **Gunakan Filter** (jika tersedia) untuk melihat data lebih spesifik.
4. **Klik pada Titik Lokasi** untuk melihat informasi detail.
